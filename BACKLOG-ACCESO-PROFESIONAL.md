# Backlog técnico — acceso profesional en Psicométricos

No desarrollar todavía.

## Objetivo
Evitar que cualquier usuario acceda indiscriminadamente a instrumentos cuyo uso requiere formación,
matrícula, credenciales o incumbencia profesional.

## Dirección propuesta
1. Perfil profesional obligatorio.
2. Profesión / especialidad / jurisdicción.
3. Matrícula o credencial cuando corresponda.
4. Niveles de acceso por instrumento/categoría.
5. Revisión de fuentes oficiales disponibles para validar matrícula.
6. Donde no exista API oficial, evaluar verificación manual o semiautomática.
7. No asumir que los registros de colegios/consejos profesionales tienen API pública.
8. Instrumentos de menor restricción podrían tener permisos diferentes, pero debe resolverse caso por caso.

## Regla
La mera creación de una cuenta no habilita automáticamente el uso de todo el catálogo.
