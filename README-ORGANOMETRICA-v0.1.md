# Landing Organométrica v0.1

## Estado
Organométrica se presenta como:
- nombre de trabajo;
- proyecto futuro;
- todavía no disponible.

## Enfoque
La propuesta conceptual está orientada a:
- estrés laboral;
- riesgos psicosociales;
- acoso laboral;
- bienestar;
- productividad;
- People Analytics.

## Flujo conceptual
Relevamiento → Procesamiento determinístico → Agregación → Dashboard → Interpretación profesional.

## Principios
- métricas agregadas;
- minimización de datos;
- privacidad;
- no usar People Analytics como vigilancia individual;
- no automatizar decisiones laborales sobre personas;
- reglas determinísticas antes que IA;
- interpretación con contexto.

## Importante
Antes de desarrollar el producto real habrá que definir:
- instrumentos y licencias;
- modelo de datos;
- anonimización;
- tamaños mínimos de grupos/reportes;
- consentimiento;
- acceso y retención;
- arquitectura;
- requisitos legales y comerciales.
