Finalidad

El objetivo es mejorar la calidad de mi práctica. No hace falta que todo sea positivo: una devolución crítica, concreta y respetuosa puede ser especialmente útil.

01
MEJORA CONTINUA

Qué hago con este feedback

Las respuestas se utilizan para revisar aspectos del proceso terapéutico, la claridad de los objetivos, la alianza de trabajo, la utilidad de las intervenciones y la organización general de la atención.

Cuando haya un volumen suficiente de respuestas, pueden utilizarse métricas agregadas para evaluar tendencias de calidad. No se publicarán respuestas individuales ni grupos pequeños que puedan facilitar la identificación de una persona.

Este formulario está deliberadamente separado de reseñas o testimonios comerciales. Si en el futuro se solicitara autorización para publicar una experiencia, se haría mediante un consentimiento específico y voluntario.

02
SIN IDENTIFICACIÓN DIRECTA

Privacidad y límites del anonimato

Este formulario no solicita nombre, correo electrónico, teléfono ni número de documento. Para reducir la posibilidad de identificación, evitá escribir nombres propios, diagnósticos, lugares de trabajo u otros detalles innecesarios en las respuestas abiertas.

Como ocurre con cualquier sitio web y servicio de correo, los proveedores técnicos pueden generar registros operativos o de seguridad. Por eso esta página se presenta como feedback sin datos identificatorios solicitados, y no como una promesa de anonimato técnico absoluto.

La respuesta se envía al canal profesional configurado para este formulario. No se utiliza para urgencias, coordinación de turnos ni comunicaciones que necesiten respuesta inmediata.
