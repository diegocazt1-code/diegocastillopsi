# Sección “Tres puertas” v0.1

Esta versión mantiene intacto el Hero aprobado y reemplaza la sección genérica de tres tarjetas por una composición editorial propia:

- filas horizontales numeradas 01 / 02 / 03;
- jerarquía diferente por público;
- etiquetas discretas;
- microinteracción al pasar el mouse;
- isotipo de Diego Castillo como marca de agua muy sutil;
- responsive para escritorio, tablet y celular.

Reemplazar en el proyecto:
- `index.html`
- `css/styles.css`
- `js/app.js` (sin cambios funcionales, se incluye completo para mantener el flujo simple).

Los assets existentes del repositorio deben conservarse.
