# Landing Psicoterapia v0.1

## Archivos
Copiar/mergear estos archivos dentro del proyecto:

- `index.html` → reemplaza el Home actual únicamente para conectar el botón "Conocer psicoterapia".
- `pages/psicoterapia/index.html` → nueva landing.
- `css/psicoterapia.css` → estilos específicos de la landing.
- `js/app.js` → se incluye completo; no tiene cambios sustanciales.

Conservar intacta la carpeta `assets`.

## Qué incluye la landing
- Hero específico de Psicoterapia.
- Motivos frecuentes de consulta.
- Cómo trabajo.
- Dos modalidades:
  - Psicoterapia flexible.
  - Procesos Terapéuticos Estructurados.
- Recorridos posibles de 6 / 8 / 12 / 16 encuentros cuando corresponda.
- Aclaración: la duración NO se compra como un pack; se define luego de admisión/evaluación.
- Posibilidad de pago anticipado sólo después de definir la propuesta.
- Qué puede incluir el proceso.
- Enfoque TCC + herramientas contextuales.
- Modalidad presencial / online.
- FAQ.
- CTA a Calendly y WhatsApp.
